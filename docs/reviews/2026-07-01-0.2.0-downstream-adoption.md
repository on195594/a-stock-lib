## 结论

`0.2.0` 的新增能力已经在 `a-stock-research` 形成真实消费闭环：主观分项证据解析与周期位置判断解析都改为调用 `a_stock_lib.contracts`。`a-stock-tracker` 已消费本包 Provider 与 `fetcher_utils`，并已锁定 `a-stock-lib==0.2.0`。`a-stock-monitor` 没有独立 Python 代码，继续通过 shell 调用 `a-stock-research/cache.py` 间接复用同一套逻辑。

## contracts.py 消费边界

- `parse_subjective_assessment_tags`：作为主观分项证据校验的代码边界，替代旧的自由文本/正则扫描实现。
- `parse_cycle_stage_tag`：作为 C/D/B 框架周期位置判断的结构化标签边界，接入点是 `cmd_set_analysis`，不是 `cmd_checklist`。
- `SubjectiveAssessment.confidence` 当前仍是解析/验证字段，尚无下游业务分支消费；`FrameworkDecision` 目前仅为类型占位，尚未实现对应解析器。

`a-stock-tracker` 已完成 `0.2.0` 版本锁定；后续重点转为保持下游文档与本包发布节奏同步，并继续加固本仓库的 contracts 对抗测试。
